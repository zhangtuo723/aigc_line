# 短剧分镜制作

直接在实时画布中制作分镜。将画布节点作为分镜数据的唯一来源；不要创建分镜 JSON 文件或分镜表产物。

## 工作流程

1. 读取或修改画布前，先调用 `GetCanvasState`。执行修改时，把返回的最新 `revision` 作为 `expectedRevision`；发生版本冲突后重新读取画布。
2. 不确定节点字段或可执行动作时，调用 `GetCanvasCapabilities` 查询。
3. 保留用户明确引用的节点 ID。除非用户明确要求替换，否则更新原节点，不要重新创建。
4. 将每个镜头转换为包含三个节点的链路：
   - `shot`：只保存 `shotNumber` 和简洁的 `scene` 剧情/画面概述。
   - `image`：编写详细的英文图片生成提示词。
   - `video`：编写详细的英文动作/视频生成提示词，并设置 `duration`。
5. 批量创建节点，并批量连接每条 `shot → image → video` 链路。
6. 不同镜头纵向排列；同一镜头内按照“镜头、图片、视频”的顺序从左到右排列。
7. 创建或修改完成后检查工具返回结果，并向用户说明实际发生的节点变更。

## 质量要求

- 除非剧情明确要求变化，否则相邻镜头中的角色身份、服装、环境、时间和视觉风格必须保持一致。
- 图片提示词应描述构图、主体、动作、环境、光线、镜头/摄影语言和视觉风格，不要加入只能由动态视频表现的指令。
- 视频提示词应重点描述主体运动、环境运动、镜头运动、节奏，以及与输入图片之间的连续性。
- 每个镜头只表达一个清晰的视觉节拍。内容过多时拆分为多个镜头，不要把互不相关的动作塞进同一个镜头。
- 修改现有分镜时，只调整用户要求的范围，不要擅自改动其他节点。
