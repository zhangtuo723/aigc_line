# 短剧镜头制作

直接在实时画布中制作生产链。画布节点是唯一数据源；不要创建分镜 JSON、分镜表或 `shot` 节点。

## 工作流程

1. 用 `GetCanvasOverview` 查找节点，用 `GetCanvasNode` 读取待修改节点，用 `GetCanvasCapabilities` 核对字段与动作。
2. 把内容拆成可独立生成和审核的 5/10/15 秒片段。片段内部可设计多个带连续时间范围的影视 Shot，但不为它们创建节点。
3. 每个片段按需要创建：
   - `image`：静帧、首帧、角色、场景或道具参考，写详细图片提示词；
   - `video`：标题包含连续片段序号，prompt 写完整动作、内部 Shot、运镜、台词、声音与衔接，设置 `duration`。
   剧情规划、旁白和时间线直接写入对应 image/video 的 prompt，不创建文本节点。
4. 批量创建节点并连接 `image → video`；多张参考图分别连接到同一个 video。不同片段纵向排列，参考图在左，视频在右。
5. 保留用户明确引用的节点 ID。除非用户要求替换，否则更新原节点。
6. 完成后读取工具结果并报告实际变更。

## 质量要求

- 相邻片段保持角色身份、服装、环境、时间、道具和视觉风格连续，除非剧情明确变化。
- 图片提示词描述主体、构图、环境、光线、材质和静态可见状态，不塞入只能由视频表现的复杂动作。
- 视频 prompt 覆盖完整时长，明确动作过程、人物反应、内部 Shot 切点、运镜、环境运动、声音和片段间衔接。
- 一个生成片段只承担一个清晰剧情节拍。内容超量时拆成多个 video，不增加独立分镜节点。
- 修改现有工作流时只调整用户要求的范围。
