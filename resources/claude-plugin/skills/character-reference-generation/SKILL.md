# 人物参考图生成

每个 `characterId` 只创建一个身份底图。不同场景下服装、妆造、湿污、伤妆或随身物发生可见变化时，以该底图为单一参考，通过图生图创建派生四联图。

## 输入

先取得角色身份档案、场景绑定的外观版本、统一视觉风格和图片工作流。角色资料至少包括：

- 年龄段、性别表达、体型、肤色、脸型、五官、发型发色及稳定识别特征；
- 身份底图使用的基准服装，以及各场景版本的上装、下装、鞋、外套、饰品、随身物、妆造与湿污/破损状态；
- 真人、动画、三维等媒介风格，以及色彩、材质和写实程度。

资料不足时做保守补全并明确标记推断；不得擅自改变已有角色身份或服装设定。

## 风格参考路由

- 目标为 3D、次世代二次元、3D 国漫、卡通渲染、三渲二、游戏 CG、影视 CG、虚拟偶像、半写实或高级时装 CG 时，必须读取 [references/3d-character-prompt-template.md](references/3d-character-prompt-template.md)，按其中的结构分别编写身份底图和场景派生图 prompt。
- **风格档位**：参考文件开头即确定风格档位。用户要求「3D 国漫、漫剧、次世代二次元、三维动画电影、游戏/影视 3D CG、非真人照片、非 2D 平涂」时默认走 **A 档·3D 漫剧写实厚涂 CG / 次世代二次元国漫**，重点写「3D漫剧写实厚涂风、顶尖国漫3D建模、UE5+PBR物理渲染、UE5全局光照、次表面散射、轮廓偏东方骨相、五官立体但不欧美化、东方骨相+西方人体结构融合、写实厚涂质感、次表面散射CG肌肤、有体积感蓬松发丝、有厚度垂坠服装、UE5全局光照、体积光、景深」。**必须保留并强调**「写实厚涂、次表面散射、UE5」等半写实三维词（这是用户要的质感）。同时**明确禁用**：
  - 2D 向：`三渲二、卡通渲染、卡通、扁平、平涂、2D、二维、漫画风、动漫贴图、块状头发`；
  - 照片向（像真人照片/证件照）：`真实摄影、照片级、像真实照片、证件照、超写实照片、写实到真人`——注意不要误禁「写实厚涂/次表面散射/UE5」；
  - 其他：`幼态、锥子脸、娃娃脸、欧美化轮廓、文字、水印、多人物`。
  只有用户明确要「真人、真人照片、照片级、超写实、实拍」时才走 B 档·纯真人写实。不要把「照片级真人」作为默认，也不要误把用户要的「写实厚涂/软质半写实」当成照片级真人而禁掉。
- 参考文件中的少年男性、年龄、身高、九头身、肤色、韩系穿搭、写实材质等只是示例变量，必须由当前角色档案覆盖；不得把示例审美强加给其他性别、年龄、体型或风格。
- 非 3D 风格不要加载该参考，继续使用本 Skill 的通用四联规范。

先合并外观完全相同的场景版本。同一角色在多个场景中服装、妆造和可见状态不变时，复用同一张底图或派生图，不重复生成。

## 资产图结构

### 身份底图

- 每个 `characterId` 只能有一个身份底图，标题使用 `角色｜身份底图｜头部+正侧背四联`。
- 身份底图使用文生图，固定角色不可变特征和基准服装；它是该角色全部派生版本的共同根节点。
- 必须先生成并审核身份底图，取得有效 `sourcePath` 后才能生成任何派生图。

### 场景派生图

- 每个不同的 `outfitId` / 可见状态版本创建一个 `image` 节点，标题使用 `角色｜场景/服装版本｜图生图四联`。
- 从身份底图直接连接到每个派生节点，使图片生成动作读取底图 `sourcePath` 并自动使用图生图。派生节点只能接入这一张人物底图作为生成参考。
- 禁止从一个场景派生图继续生成另一个场景派生图；所有分支都必须直接回到身份底图，避免逐代换脸和细节漂移。
- 派生 prompt 必须明确“严格继承参考图中的脸、年龄、体型、肤色、发型和识别特征，只改变指定服装/妆造/状态”，并完整描述目标版本。
- 如果某个场景外观与身份底图完全一致，直接复用身份底图，不创建派生节点。

## 四联图规格

- 一张图只表现同一个角色和同一个外观版本。
- `aspectRatio` 固定为 `16:9`。
- 从左到右严格排列四个独立画面：头部近景、全身正面、全身标准侧面、全身背面。
- 左侧头部近景清楚展示脸型、五官、肤质、眉眼、鼻唇、发际线、发型、耳部与识别标记；构图从头顶到肩部，不裁掉头发和下巴。
- 右侧三个全身角度展示完整头顶、手、腿和鞋，比例一致、地面线一致、尺寸接近。
- 正面、侧面和背面使用自然中立站姿：双臂自然下垂或轻微放松，不摆 A-pose、T-pose、战斗姿势或夸张动作。
- 四个画面必须保持同一张脸、年龄、体型、发型、服装、鞋、饰品、材质和颜色，不得把四联图生成成四个不同人物。
- 使用纯净中性背景、均匀柔和棚拍光、低透视畸变和清晰服装轮廓。除必要的分隔留白外，不生成文字、标签、水印、Logo、边框装饰或额外人物。

## 创建与生成

1. 调用 `GetCanvasCapabilities`。身份底图选择真实可用的文生图工作流；派生节点选择支持图生图的工作流，不要猜测 `workflowId`。
2. 先创建每个角色唯一的身份底图节点和中文 prompt。3D 风格必须按专用参考组织渲染、骨相、比例、服装结构、棚拍灯光与负面约束。
3. 汇总身份底图节点、工作流和中文提示词摘要，明确询问是否开始生成。只有用户明确同意后才能调用 `InvokeNodeAction(generate)`；然后等待全部节点离开 `generating`，读取实际图片并审核四栏顺序、身份辨识度、全身完整性和自然站姿。不合格时说明重做范围，重新确认后再生成。
4. 底图合格后创建场景派生节点，写入中文图生图 prompt，并建立 `身份底图 → 场景派生图` 连线。不得在底图尚无 `sourcePath` 时触发派生生成。
5. 展示派生节点、对应底图、场景/服装版本、图生图工作流和摘要，单独取得明确确认后生成派生图。
6. 检查每张派生图是否继承底图身份、四栏仍为同一人、只发生指定外观变化。身份变化时修改派生 prompt 或回到底图修复；底图一旦替换，所有依赖它的派生版本都必须标记为待重新生成。
7. 若由其他生产 Skill 调用，返回 `characterId → baseNodeId → variantNodeIds → sceneIds` 映射和两个阶段的生成计划，由调用方统一执行授权门。

## 提示词骨架

把下列结构写成自然、具体的中文提示词，不保留占位符：

```text
身份底图：横向16:9角色设定四联图，同一位[角色身份]，统一[视觉风格]，纯净中性背景与均匀棚拍光。从左到右严格四栏：第一栏头部近景；第二栏自然站立全身正面；第三栏自然站立全身标准侧面；第四栏自然站立全身背面。完整显示[不可变身份特征]与[基准服装]，四栏同脸同体型同服装，无文字、标签、水印或额外人物。

场景派生图：以输入身份底图为唯一人物参考，严格保持参考图中的脸型、五官、年龄、肤色、体型、发型和识别特征不变，只将四栏人物统一调整为[目标场景服装/妆造/湿污破损状态]。保持横向16:9四联顺序：头部近景、自然站立全身正面、自然站立全身侧面、自然站立全身背面；纯净中性背景、均匀棚拍光、四栏同人同装，无文字、标签、水印或额外人物。
```
