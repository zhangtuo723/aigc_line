# 3D 人物四联图提示词参考（3D 漫剧写实厚涂 / 写实分档）

当目标风格包含「3D、国漫、漫剧、次世代二次元、三维动画电影、游戏 CG、虚拟偶像、半写实、高级时装 CG」时读取本参考。使用 Skill 提供的四联规范并按下面选择风格档位组织提示词。

## 最重要：先确定风格档位（不要默认照片级写实，也不要默认 2D 平涂）

### A 档 · 3D 漫剧写实厚涂 CG / 次世代二次元国漫（默认）

用户要求「3D 国漫、漫剧、次世代二次元、三维动画电影、游戏/影视 3D CG、非真人照片、非 2D 平涂」时用本档。目标是国漫 3D 电影 / 漫剧那种**写实厚涂质感**：`UE5 + PBR 物理渲染`、`次表面散射`、`东方骨相 × 西方人体结构`、有体积与立体光影；**绝不是 2D 平涂卡通风，也绝不是像真人照片一样的写实**。

**必用表达：**
- 媒介/渲染基座：`3D漫剧写实厚涂风`、`顶尖国漫3D建模`、`UE5+PBR物理渲染`、`UE5全局光照`、`次表面散射`、`三维CG电影质感`、`写实厚涂质感`
- 骨骼与审美：`轮廓偏东方骨相`、`五官立体但不欧美化`、`东方骨相+西方人体结构融合`；
  - 女性：`女性曲线自然、拒绝过度“幼态”或“锥子脸”、强调英气与柔美平衡`
  - 男性：`五官立体深邃、轮廓利落冷硬、冷调`（按角色气质，可含`锋利剑眉`、`琉璃眼眸`、`眼尾微勾`、`鼻尖高光、唇珠高光`、`下唇小黑痣`等具体识别特征）
- 材质：`细腻的次表面散射CG肌肤、带健康红晕、鼻尖与唇珠高光、无真实毛孔`、`有体积感的蓬松发丝、随光源有厚度与反光`、`有厚度与垂坠感的写实厚涂服装、面料有肌理但偏CG`
- 光照：`UE5全局光照、柔和立体光影、次表面散射透光、明暗过渡自然、弱化照片暗部`
- 渲染：`三维动画电影级渲染、体积光、景深`

**构图（四联，固定）：** 左侧为超大人物脸部/胸像**正面特写**（完整展示头顶、发型、五官、肩颈与上胸）；右侧水平并排 **3 张全身立绘：正面全身、45° 侧面全身、背面全身**。纯色/无缝中性背景，自然站立、双臂自然下垂，不用 A-pose / T-pose，四栏必须同一个人物。

**禁止出现：**
- 2D 向：`三渲二、卡通渲染、卡通、扁平、平涂、2D、二维、漫画风、动漫贴图、AI平涂、块状头发`
- 照片向（会像真人照片/证件照）：`真实摄影、照片级、像真实照片、证件照、超写实照片、写实到真人`——注意 `写实厚涂`、`次表面散射`、`UE5` 是保留项，**不要误删**
- 其他：`幼态、锥子脸、娃娃脸、欧美化轮廓、过度整容感、文字、logo、水印、多人物`

### B 档 · 纯写实 / 照片级真人（仅当用户明确要真人写实）

用户明确写「真人、真人照片、照片级、超写实、实拍」时才启用照片级写实表达。默认不启用。

## 使用原则

- 把示例视为结构与细节密度参考，不要逐字复制。按角色档案替换性别、年龄、骨架、身高、体型、气质、发型、妆容、服装和配饰。
- 「18—20 岁男性」「锋利剑眉」「韩系潮男」等都是示例变量，不是全局默认，只有剧情明确需要才保留。不要用示例偏好覆盖用户指定的女性、儿童、老人、不同肤色、不同审美或非人角色。
- 四联布局固定：左侧超大正面脸部特写，右侧依次为正面全身、45° 侧面全身、背面全身。三个全身角度取自然中立站姿、双臂自然下垂，不用 A-pose / T-pose。
- 身份底图重点固定不可变身份；场景派生图必须以底图为唯一人物参考，只改变明确指定的服装、妆造、湿污、伤妆或随身物状态。

## 推荐结构（A 档默认）

1. 媒介与整体气质：3D 漫剧写实厚涂 / UE5+PBR 国漫；角色总体气质；
2. 年龄、性别表达、东方骨相/西方结构、五官、发型、肤色/材质与识别特征；
3. 四栏必须同一人物的一致性声明；
4. 16:9 四联布局、各栏景别、角度与自然站姿；
5. 身体比例与完整入镜要求（女子自然曲线/男子利落冷硬，拒绝幼态/锥子脸）；
6. 服装轮廓、层次、颜色、材质、结构与背面设计（写实厚涂、叠穿、有垂坠感）；
7. 纯色/无缝中性背景、UE5 全局光照、次表面散射、柔和立体光影；
8. 与当前角色冲突相关的精简负面约束（2D 平涂/照片级真人/文字/水印/多人物）。
