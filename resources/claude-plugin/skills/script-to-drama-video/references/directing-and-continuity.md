# 分镜导演与连续性方法

在规划新短剧、重做片段结构或修复连续性问题时读取本文件。它只定义导演决策；节点、工作流和 H3 格式仍以主 Skill 与对应专项 Skill 为准。

## 1. 从戏剧节拍到生成片段

先把每场戏写成 `目标 → 阻力 → 行动 → 反应 → 信息变化 → 情绪转折 → 离场钩子`。一个生成片段只承载一个可感知的变化；地点、时间、人物目标或状态明显改变，或者动作与对白超过时间预算时拆片。

每个片段先确定：观众在结尾比开头多知道、感到或期待什么。无法回答时，该片段没有独立存在的理由，应合并或重写。

## 2. 先调度，后选镜头

先画清人物和道具在空间里的起点、路径、停点、视线、遮挡和结束位置，再选择景别、机位和运镜。不要用运镜代替人物行动。

记录：

- 主体在画面左/中/右和前/中/后景的位置；
- 面向、视线目标、动作手、持有物和接触关系；
- 出入口、轴线、越轴条件和关键遮挡；
- 动作开始状态、可见过程和结束状态。

## 3. 切镜必须有理由

默认优先一个可执行的连续 Shot。只有下列情况才切镜：

- 引入新的剧情信息或空间关系；
- 展示决定性的动作细节或道具状态；
- 捕捉会改变观众理解的关键反应；
- 时间、地点、主观视角或叙事焦点发生变化；
- 当前构图无法清楚表现下一动作。

每次切镜写明“新信息”和“切出依据”。避免为了节奏而无理由切镜，也不要在 5 秒内堆叠无法完成的多段动作。

## 4. 镜头字段

每个内部 Shot 至少包含：

- 连续时间范围；
- 叙事目的与新增信息；
- 景别、角度、机位和构图；
- 人物/道具的空间位置、动作过程、表情和视线；
- 镜头运动或明确锁定；
- 光影、环境运动、台词、拟音和环境声；
- 进入方式、结束画面和下一镜衔接。

运镜使用一个主运动，必要时加一个幅度很小的辅助运动。复杂表演、遮挡互动和对白优先稳定机位。

## 5. 连续性账本

为每个生成片段记录开场和结束状态：

| 维度 | 必记状态 |
|---|---|
| 人物 | 身份、服装、妆造、伤污、情绪、站位、朝向、视线 |
| 道具 | 数量、外观、持有人、所在手、位置、开合/破损状态 |
| 场景 | sceneId、时间天气、灯光方向、家具和出入口 |
| 动作 | 起始姿势、动作阶段、结束姿势、是否跨片延续 |
| 声音 | 台词尾音、环境底噪、拟音、声音桥、静默点 |
| 摄影 | 轴线、人物左右关系、结束景别、运动方向 |

相邻片段至少使用一种可验证衔接：动作匹配、视线匹配、构图呼应、声音桥、光色延续或明确的时空转场。不要只写“自然转场”。

## 6. 时间与执行预算

- 为台词、停顿、反应、动作和切镜分别留时间；中文自然对白通常按约 3–5 字/秒预估，但表演性停顿会降低密度。
- 一个 Shot 只承担一个主要动作变化。需要多次接触、快速转身、复杂手部操作或多人抢夺时，减少切镜或拆成多个生成片段。
- 参考素材不能替代时间预算。模型看得到角色图，不代表能在短时长内完成任意动作。

## 7. 常见失败与导演级修复

| 失败 | 优先修复 |
|---|---|
| 人物漂移 | 减少同时出场人物；核对当前服装参考；强化不可变身份特征 |
| 空间跳变 | 复用 sceneId；重写人物起止位置、轴线和出入口 |
| 动作未完成 | 删除次要动作；延长片段或拆片；明确动作三阶段 |
| 像幻灯片 | 增加可见状态变化和环境运动，不靠无意义推拉镜头 |
| 过度切镜 | 合并没有新信息的 Shot；改为连续调度和单一运镜 |
| 道具穿帮 | 固定数量、持有人、左右手和每个切点的状态 |
| 对白错人 | 绑定说话者、声线、口型和沉默角色反应 |
| 音画错位 | 把拟音触发点写入具体动作时间，减少同一时刻的声音事件 |

修复时先改导演包，再调用 `h3-prompt-writing` 重写最终 prompt；不要直接在最终 H3 文本里零散打补丁。
