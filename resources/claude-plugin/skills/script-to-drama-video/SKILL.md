# 剧本转 AI 短剧

把输入深化为可生成、可审核、可衔接的视频片段。画布只承载生产资产：人物/场景/道具 `image`、片段 `video`、必要的 `audio` 与放大节点。不要创建 `text` / `shot` 节点、分镜表或 `.storyboard.json`；剧情规划、旁白和时间线直接写入对应 image/video 的 prompt。

严格区分：

- **生成片段**：一次独立 H3 生成和审核，对应一个 `video` 节点，时长只能为 5/10/15 秒。
- **片段内 Shot**：同一视频内部按时间发生的真正镜头，可有一个或多个，只写入导演包和最终 H3 prompt，不创建 Canvas 节点。

## 总流程

```text
确认创作参数 → 深化剧本与节拍 → 建立角色/服装/场景/道具清单
→ 调用人物与场景参考图 Skill 创建角色底图和场景图
→ 用户确认 → 生成并检查角色底图/场景图
→ 从角色底图创建图生图场景变体 → 再次确认 → 生成并检查人物变体
→ 拆分生成片段并设计内部 Shot
→ 创建 video 节点、引用数组和 image → video 连线
→ 逐片段调用 h3-prompt-writing → 用户确认
→ 生成视频 → 按 video 节点审核 → 修订或交付
```

## 1. 确认创作参数

先判断输入是否完整。只有用户要求忠实改编却缺少关键正文时才索取材料；用户明确只给梗概或创意时，可在不违背核心设定的前提下扩写。

一次性确认：

- 画幅：`16:9`、`1:1` 或 `4:3`；
- 统一视觉风格、时代、地域、色彩和材质；
- 改编强度：默认忠于核心、艺术化表达；逐字逐场还原必须由用户明确要求；
- 台词/旁白语言、角色声线；默认无 BGM，只保留台词、旁白、环境音和拟音；
- 5/10/15 秒时长策略。不能把超量对白和动作硬塞进 15 秒。

## 2. 深化剧本

默认保留核心人物关系、关键事实、主要冲突、因果、决定性事件和结局方向。可以：

- 重排信息揭示顺序，增加悬念、伏笔、对照、动作匹配和声画桥；
- 把心理与说明转成可见动作、表情、停顿、视线、空间调度、道具和声音；
- 补写不改变人物意图的对白、反应、潜台词或旁白；
- 合并重复信息，补足进入、承接、升级、转折和收束节拍。

改变核心动机、关键事件、人物关系或结局前必须确认。严格还原模式下保留原台词、事件顺序和场次边界，只补足拍摄所需的动作、机位、声音和时间分配。

逐场建立“目标 → 阻力 → 行动 → 反应 → 信息变化 → 情绪转折 → 离场钩子”，并记录：

- 场景目的、开场钩子、高潮落点与下一场声画桥；
- 角色进入状态、欲望、策略和场末变化；
- 必须保留的事实/原句与允许改写的部分；
- 可视化动作、关键反应、道具、环境和声音母题；
- 每句对白、画外对白、内心独白和旁白的说话者与剧情位置。

向用户展示改编策略和主要增补、合并或重排。只有触及核心剧情时才等待额外批准。

## 3. 建立资产清单

为每个角色分配稳定 `characterId`，记录年龄段、体型、肤色、脸型、五官、发型、识别特征、气质和姿态习惯。

每个 `characterId` 指定一个基准外观作为唯一身份底图。再按“角色 × 剧情阶段/服装/可见状态”建立 `outfitId`，并绑定使用它的 `sceneId`；只有颜色、材质、版型、鞋帽、饰品、妆造、破损、湿润或沾污等确实变化时才新建版本。外观完全相同的多个场景必须复用同一版本。

为每个不同地点或明显变化的环境建立 `sceneId`，记录空间布局、材质、固定家具、出入口、时间、天气、主光方向、色温和氛围。同一地点的昼夜、天气、灯光或破坏程度明显变化时建立新版本。

关键道具只有在跨场保持外观、被角色持有或需要特写辨识时才创建独立 `image` 参考节点。普通固定物件直接进入场景参考图。

## 4. 委派参考图

人物和场景生成不得在本 Skill 内复制模板。

### 人物

调用 `aigc-canvas:character-reference-generation`，传入完整角色身份档案、基准外观、每个 `outfitId` 与场景绑定关系和统一视觉风格。必须形成两层人物资产图：

- 每个角色只有一个文生图身份底图，单张横向 16:9 四联，从左到右为头部近景、自然站立全身正面、侧面、背面；
- 不同场景的服装、妆造或状态版本必须以该身份底图为唯一参考，通过 `身份底图 → 场景派生图` 连线触发图生图；
- 所有派生分支直接连接身份底图，禁止用一个变体继续派生另一个变体；
- 外观与底图相同的场景直接复用底图，外观相同的多个场景复用同一派生图；
- 底图与派生图的三个全身角度都不使用 A-pose 或 T-pose。

### 场景

调用 `aigc-canvas:environment-reference-generation`，传入每个 `sceneId`、空间档案、视觉风格和成片画幅。每个场景版本应得到一个无人 `image` 节点：

- 高机位俯视全景，完整交代空间、出入口、行动路线、家具与关键道具；
- 保留真实透视、立面、材质和纵深；
- 不生成普通平视环境图、二维户型图或多视图拼贴。

参考图分阶段生成，不能一次并发触发全部人物节点：

1. 汇总角色身份底图和环境图的节点、工作流与中文提示词摘要，询问是否开始生成第一阶段参考图；确认后生成并等待全部完成。
2. 读取并确认每个角色底图已有有效 `sourcePath` 后，创建/核对人物场景派生节点及 `身份底图 → 派生图` 连线；汇总底图映射、场景/服装版本和图生图工作流，重新询问是否开始生成派生人物图。
3. 只有第二次明确确认后才能调用派生节点的 `InvokeNodeAction(generate)`。不得让缺少底图输出的派生节点退化为独立文生图。

读取实际图片并检查底图四联的顺序、身份辨识度、全身角度完整性和自然站姿；逐个对照底图检查派生图是否同脸、同年龄、同体型、同肤色、同发型，只改变指定服装/妆造/状态；检查环境图是否确为无人俯视全景、空间可读、布局与光线正确。不合格时说明原因、修正对应节点，并在重做前重新取得确认。底图重做后，其全部派生图必须重新生成和复核。

## 5. 规划生成片段

参考图合格后，把深化剧本拆成可独立生成和审核的 5/10/15 秒片段。每个片段围绕一个明确节拍，包含开场状态、动作推进、人物反应、信息/情绪变化和结尾落点。

当剧情目标或人物状态显著改变、地点/时间改变、对白与动作超出预算、需要独立审核，或图片引用超过 9 张时拆片。中文自然对白按约 3–5 字/秒估算，同时为停顿、反应、动作和切镜留时间。

为每个片段设计连续覆盖完整时长的内部 Shot：

- 使用 `SEGxx-yy` 编号；
- 第一段从 0 秒开始，后段起点等于前段终点，末段结束时间等于片段时长；
- 明确景别、机位、构图、人物位置、动作过程、表情/视线、运镜、声音和切出依据；
- 只有引入新信息、关键反应、新空间关系、新状态或新时间时才切镜；
- 保持轴线、视线、人物左右位置、动作、道具、光源和声音连续；
- 片段间明确动作承接、视线匹配、声音桥、构图呼应或光色衔接，不能只写“自然转场”。

向用户展示片段规划和内部 Shot 时间线。每个片段至少列出目的、时长、开场、动作/反应、台词/旁白、声音、结尾和衔接。

## 6. 创建视频节点与引用

每个生成片段直接创建一个 `video` 节点，不创建配套 `shot` 节点：

- 标题包含连续片段序号，例如 `SEG02｜客厅质问`；
- `workflowId` 固定为 `minimax-h3-r2v`；
- `duration` 为 5、10 或 15；
- `aspectRatio` 与成片一致；
- `referenceImageNodeIds` 最多 9 个，顺序为本片段出场人物的当前场景四联图（按首次出场/对白顺序；无派生版本时使用身份底图）→ 当前环境俯视全景图 → 必需关键道具；
- 只有实际使用的服装和场景版本进入数组；
- 从所有引用 image 节点连接到 video 节点；
- 不设置 `firstFrameNodeId` / `lastFrameNodeId`。

剧情规划、旁白、时间线和最终生成要求必须完整写入对应 video prompt，不创建额外文本节点。不同片段纵向排列，参考资产放在左侧或上方。

## 7. 委派 H3 提示词

为每个 video 整理导演包：

- 目标时长、画幅、媒介风格、色彩、光线、表演尺度；
- 片段目的、开场构图、人物位置、动作路径、表情/视线、道具状态、结束构图；
- 内部 Shot 时间线、切点、每次切镜的新信息和运镜；
- 完整台词/旁白、说话者、声线、情绪、语速、口型与沉默角色反应；
- 环境声、同步拟音、非语言人声和无 BGM 要求；
- 与相邻片段的声画衔接；
- 三类 reference 数组的真实顺序和每个素材用途。

逐片段调用 `aigc-canvas:h3-prompt-writing`，明确使用 full-reference Ref2VA。不得自行仿写或维护 H3 官方模板。由该 Skill 生成并校验引用标签、结构、时间戳、对白和声音字段。

写入 video 的 `prompt` 前核对：

- 引用编号与真实数组槽位完全一致，失败素材不得过滤后重新编号；
- 切点严格落在时长内，动作和对白有可执行预算；
- 原语言、说话者、口型和旁白规则正确；
- prompt 保留片段目的、表演、内部 Shot 与片段间衔接；
- 输出符合 `h3-prompt-writing` 的格式。

展示全部视频节点的片段摘要、内部 Shot、引用映射、声音与改编说明。只有用户明确同意后才能生成视频。

## 8. 审核与交付

等待所有 video 节点离开 `generating`。每个片段调用 `ReviewStoryboardVideo`，直接传对应 `video` 节点 ID。工具读取实际视频、音轨、原始 H3 prompt 和有序参考素材，检查：

- 人物身份、服装、场景、道具、空间、光线和片段间连续性；
- 脸手肢体、物体融合、穿透、漂浮、人物/道具增减、闪烁、重影、黑绿帧和清晰度骤降；
- 内部 Shot、动作、运镜、转场和切点；
- 台词完整性、说话人、口型、音效与音画同步；
- 爆音、削波、杂音、电流声、金属/乱码语音、重复截断、掉声、音量跳变和剪辑断裂。

工具只返回审核证据、问题和建议，不替生产 Agent计算总分或决定通过/重做。需要修改 H3 prompt 时，把审核结果和修订导演包再次交给 `h3-prompt-writing`；向用户说明重做原因和范围，重新取得确认后只重做受影响 video。

用户需要剪映草稿时调用 `aigc-canvas:jianying-draft`，按 video 标题中的片段序号排列。交付时列出人物资产、场景资产、生成片段数、内部 Shot 数、失败/重做情况和最终路径。

## 画布规范

- 用 `GetCanvasOverview` 查规模和 ID，用 `GetCanvasNode` 读具体节点，用 `GetCanvasCapabilities` 核对字段和动作。
- 优先批量创建、更新和连接；写入采用最后写入者生效，不传版本号。
- 只写能力表声明的字段。生成完成顺序不等于片段顺序，始终按节点 ID、标题、引用数组和 `sourcePath` 对齐。
- 保留用户明确引用或要求修改的节点 ID；不要为了方便整批重建。
