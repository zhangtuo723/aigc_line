# 场景参考图生成

为每个不同 `sceneId` 创建一张可被多个视频片段复用的空间锚点。场景参考图服务于空间、材质、光线和行动路线连续性，不直接充当成片构图。

## 输入与归并

先取得场景清单、成片画幅、统一视觉风格和图片工作流。每个场景档案至少包括：

- 地点、时代、用途、空间尺度、层高和主要结构；
- 出入口、窗、走廊、楼梯、人物行动路线和关键视线；
- 固定家具、关键道具、墙地顶材质及磨损状态；
- 时间、天气、主光方向、色温、实用光源和阴影关系；
- 剧情阶段造成的布置、污染、湿润、损坏或灯光变化。

同一地点只有在布局、时间、天气、灯光或破坏状态发生可见变化时才新建版本。外观相同的场次复用同一个 `sceneId` 和节点。

## 画面规范

- 一张图只表现一个场景版本，画幅与成片一致。
- 使用高机位斜俯视全景，镜头足够高以同时交代地面、真实立面、纵深和主要遮挡关系，但不要做成垂直鸟瞰平面图。
- 完整显示出入口、行动通道、固定家具、关键道具和空间分区；让人物将来从哪里进入、移动、停留和离开一目了然。
- 保持真实透视、尺度、材质、光源方向和阴影，不使用等距插画、剖面图、建筑蓝图或多宫格。
- 场景中不得出现人物、人体局部、人形模特、镜中人或可辨识角色；普通环境陈设可以保留。
- 不生成文字、标签、尺寸线、水印、Logo、边框或额外视图。

## 创建与生成

1. 调用 `GetCanvasCapabilities`，选择真实可用的文生图工作流，不猜测 `workflowId`。
2. 为去重后的每个场景版本创建一个 `image` 节点，标题使用 `场景｜状态版本｜无人俯视空间全景`，prompt 使用中文。
3. 在 prompt 中写明空间结构、出入口、行动路线、固定物、材质、时间天气、主光方向和禁止项；不要把人物动作或视频运镜塞进场景图。
4. 汇总待生成节点、sceneId、工作流和中文提示词摘要，明确询问是否开始生成。只有用户明确同意后才能调用 `InvokeNodeAction(generate)`。
5. 等待全部节点离开 `generating`，读取实际图片并检查：是否无人、是否高机位斜俯视、空间是否完整可读、立面和纵深是否真实、布局/材质/光线是否与档案一致。
6. 不合格时只修改受影响节点；说明原因和重做范围，重新取得明确确认后再生成。
7. 若由生产 Skill 调用，返回 `sceneId → nodeId → sourcePath → reusedBySegmentIds` 映射，并标明尚未生成或待重做的版本。

## 中文提示词骨架

把下列结构写成自然、具体的中文，不保留占位符：

```text
无人场景空间设定图，[视觉媒介与时代风格]，[成片画幅]。高机位斜俯视全景，以真实透视完整展示[场景名称]的地面、立面、纵深、出入口、行动通道、固定家具与关键道具；明确[空间布局和路线]。材质为[墙地顶与家具材质]，处于[时间/天气/状态]，主光从[方向]进入，[实用光源与色温]，阴影方向一致。画面中无人、无人形、无文字标签、无尺寸线、无水印，不是垂直鸟瞰平面图、二维户型图、等距插画、剖面图或多视图拼贴。
```
